# H2 复核实验 —— 第一轮（`h2-01`）

> **这一页是给复核者看的，本身不含任何剧透。** 读它是安全的。

## 你要做什么

1. 打开 [`packets.md`](packets.md)，从 `H2-01` 读到 `H2-15`。
2. **每题限时 5 分钟**，只读那一页。
3. 判 **`对` / `错` / `无法判断`**，填进 [`answer-sheet.yaml`](answer-sheet.yaml) 的 `verdict`。
   `note` 选填，写一句「为什么」对事后分析很有用。

## 三条把意思说清楚的

- **「对」= 你认为系统这次给出的结果是对的。**
  **拒答也是一种结果** —— 十五题里有相当一部分是拒答，那时你判的是
  **「这次拒答对不对」**，不是「这个数对不对」。
- **「无法判断」不是「不确定就选它」。** 它是一个**被单独统计**的读数
  （`EVAL_CASES` §4.3：占比 > 20% ⇒ 即使一致率达标也要补齐证据链重测）。
  选它的意思是：**这一页的信息不足以让我下结论**。
- **留空 ≠ 无法判断。** 没填完的答卷会被拒绝算数（fail-closed），
  因为「没填」和「填了无法判断」混同会让上面那道反向检验失真。

## 复核之前**不要**读这三样

它们都写着哪几道是错题：

| 别读 | 里面有什么 |
|---|---|
| `keymap.json` | 匿名号 → 原题号的对照表 |
| `.planning/phases/02-execution-web/02-03-PLAN.md` 的 `<context>` 一节 | 逐条写着这一轮的三条限定，含错题分布 |
| `eval/frozen-01/cases/*.yaml` | 题面里的 `expected` / `rationale` / `attribution_hint` 就是标准答案 |

题包本身**不含**上面任何一样 —— 有测试逐条守着
（`tests/test_h2.py`，含一条把标准答案硬塞进题包看它会不会红的反空转）。

## 填完之后

```bash
.venv/Scripts/python -m eval.h2 --suite frozen-01 --sheet docs/agent/h2-01/answer-sheet.yaml
```

它会算一致率、无法判断率、以及**错题子集上的原始计数**，
并按 `EVAL_CASES` §4.2 给判定。

⚠️ **这一轮是普查，不是随机抽样**，且 `≥5 题答错` 这条不满足 ——
原因与代价写在 `D-037` 里，结论必须连同那几条标注一起转述。
**器械不替你把结论说圆**：缺任一条强制标注，它拒绝给结论。

## 这一份是怎么生成的

```bash
.venv/Scripts/python -m eval.h2 --suite frozen-01 --seed 20260905
```

种子记在 `keymap.json` 里，同种子可复现。
**对照表在复核开始之前就已经落盘并进了版本控制** ——
这样事后没有人能把匿名号重新映射一遍。
