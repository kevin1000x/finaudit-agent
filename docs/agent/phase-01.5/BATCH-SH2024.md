## 复跑

使用本仓 Python 环境并安装 `pip install -e ".[crosscheck]"`。从仓库根目录运行，先准备与清单匹配的本地公开 PDF。新实验使用新输出目录；对同一次实验续跑可以复用目录。第一次跨源核对需要网络。

```bash
rvp=../cninfo-financial-analyzer/data
out=data/results/batch-sh2024
python scripts/batch_extract.py extract --pdf-dir "$rvp/raw/rvp" --manifest "$rvp/results/rvp_manifest.json" --year 2024 --out "$out"
python scripts/batch_extract.py crosscheck --pdf-dir "$rvp/raw/rvp" --manifest "$rvp/results/rvp_manifest.json" --year 2024 --out "$out"
python scripts/batch_extract.py summarize --out "$out" --financial-stocks 600030 600390 600816 600908 600926 601229 601288 601318 601456 601658 601990 603093 603323
```

抽取器对应提交 `8e36bf5`。上游清单 SHA-256 为 `3d5e9a0224e41ebfea8fcd0184f4b1e8fe2f7b3873088c24d4b2afb55ee10c93`。对照响应于 2026-11-25 获取，保存在本机实验目录的 `akshare/`。日后重新联网取值可能对应更新的披露版本。
