## §3 三条实测撞出来的事，Task 2 定容差时必须知道

### （a）🔴 返回类型是 `float`，不是字符串也不是 `Decimal`

`流动负债合计` 那一行最直观：AKShare 给的是 **`48697611501.2`**，
而报表上印的是 **`48,697,611,501.20`** —— **值相等，但末位的 `0` 被 float 吃掉了**。

⇒ **两条后果**：

1. **不能拿字符串比。** `"48697611501.2" != "48697611501.20"`，
   而这两个数在数值上完全相同。跨源比较必须在**数值域**做，
   且 PDF 侧必须先 `Decimal` 化再比。
2. **float 有精度上限。** IEEE 754 double 的尾数是 53 bit ⇒ 能精确表示的整数上界
   约 `9.007e15`。以「分」为单位看，茅台的资产总计是 `2.727e13` 分，**还很宽裕**；
   但一家万亿级资产的公司（如大型银行，`~4e13` 元 = `4e15` 分）就已经贴近上界。
   ⚠️ **本样本没有触及这个上限，所以这是一条推理不是实测** ——
   按 `F-1`，记为「结构上存在的风险」，不写成「已观察到的失效」。

**⇒ 对 Task 2 的直接输入**：容差判定必须用 `Decimal`，且 AKShare 侧的 `float`
要经 `Decimal(repr(v))` 而不是 `Decimal(v)` 转换 ——
后者会把二进制浮点的全部尾巴带进来（`Decimal(48697611501.2)` 得到
`48697611501.2000007629...`），凭空造出一个不存在的差额。
本报告的对照就是用 `Decimal(repr(v))` 算的。

### （b）存在值为 `NaN` 的列，且它与「零」「缺失」是三件事

`所有者权益` 这一列在 2023 年度是 `nan`（真正的合计在
`所有者权益(或股东权益)合计` 那一列）。

⇒ 与我们在抽取层建的三态是同一件事：
`VALUE_PRESENT` / `EMPTY_CELL`（行在格子空 = 0）/ `ROW_ABSENT`（整行不存在 = 缺失）。
**AKShare 侧的 `NaN` 对应哪一态，Task 3 必须显式决定，不许默认成 0。**
本任务的固件把 `NaN` 序列化成 `null` —— **`null` 是「AKShare 这里是 NaN」的忠实记录**，
不是「值为零」。

### （c）列名是**原始中文列名，不携带任何口径说明**

`所有者权益` 与 `所有者权益(或股东权益)合计` 两列并存，
名字相似、含义不同、其中一个还是空的。

⚠️ **括号是半角 `()` 不是全角 `（）`** ——
而 PDF 版面上印的是全角：`所有者权益（或股东权益）合计`。
逐字相等匹配下这是**两个不同的串**。

⇒ **对 Task 3 的直接输入**：AKShare 列名到 `field_id` 的映射必须走**独立文件**
（`data/mappings/akshare/*.yaml`），**不能与 PDF 标签混在一份里** ——
它们连标点都不一样。且匹配同样是**逐字相等**：
`references/cninfo.md:204-213` 记着 cninfo 用子串匹配对齐 AKShare 列名，
产出三处「看起来合理、实际取错」的映射。

## §4 诚实的限定

1. **单公司单年单接口。** 九个科目全部来自 `sh600519` 的 `20231231` 一行，
   接口是新浪源（`stock_financial_report_sina`）。
   **AKShare 还有别的财报接口（东财源等），它们的单位未验证。**
2. **「差额全为 0」不等于「AKShare 是可靠的对照源」。** 它只等于
   **在这一家一年的这九个科目上，两个源给出了同一个数**。
   `D-013` 的立场不因此改变：财务数值仍以年报 PDF 原文为准，AKShare 只作对照。
3. **float 精度上限那条是推理，不是实测**（见 §3a）。
4. **没有跑任何容差判定** —— 那是 Task 2 的事，而 Task 2 需要的正是这份事实。

## §5 给 Task 2（容差 checkpoint）的输入摘要

- **单位一致**（都是元、精确到分）⇒ **不需要单位换算**，
  `units.to_yuan` 在 AKShare 这一侧是恒等变换。
  ⚠️ 但**不能因此删掉归一化那一步** —— 它防的是「换一个源/换一家公司就不一样了」，
  而本轮只验了一个源一家公司。
- **本样本上九个科目的差额全部精确为 0** ⇒
  容差取多少，在这份样本上**都不会触发 `source_disagreement`**。
  ⚠️ 这意味着**本样本无法用来标定阈值** —— 它只能证明「阈值不必为了容纳系统性偏移而放宽」。
- **比较必须在 `Decimal` 域做**，AKShare 的 `float` 走 `Decimal(repr(v))`。
- **`NaN` 的语义要显式决定**，不许默认成 0。
