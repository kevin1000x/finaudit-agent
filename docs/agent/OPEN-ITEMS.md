### A-6 — 坐标重组法的三个真实失效模式（Phase 1.5 必须设计进去）
- **归属**：agent，Phase 1.5 抽取器的设计约束
- 都是 2026-08-16 在茅台 2023 上实测出来的，不是假想：

1. **长标签折行 ⇒ 数值自成一行，行首规则永远匹配不上**（`total_equity` 就是这么丢的）：
   ```
   归属于母公司所有者权益
   215,668,571,607.43 | 197,480,041,239.46
   （或股东权益）合计
   ```
   → **必须基于 x 坐标分列（标签列 / 附注列 / 数值列），不能基于行首。**
2. **附注编号列会被当成数值**：列结构是 `项目 | 附注 | 本期 | 上期`，
   `应收账款 | 5 | 60,373,410.41 | 20,937,144.00` 里的 `5` 是附注号。
   → 按**列位置**剔除，不能按值形状——附注号与小额科目在正则上不可区分。
3. **续页不重复表头，且母公司表紧接合并表**：
   `单位:元 币种:人民币` 与列名只印在表的**首页**（茅台是 p58），p59–p60 是裸续页；
   p61 一页之内从合并表切到母公司表（合并资产总计 272.7 亿 vs 母公司 171.6 亿）。
   → 宽页窗口会**静默混入母公司数**。这正是 `parent_only_scope` 的用武之地，
   该 flag 此前零引用（B-3），**现在有实证承载场景了**。
- **判据**：抽取器对这三条各有一个用茅台真实数据驱动的回归用例。

**三条已在第二次探测中各自跑通（2026-08-16 同日，见 A-4）**，处置方式如下——
但**判据仍是待办**：探测跑通 ≠ 有回归用例，代码还在 scratchpad。

| 失效模式 | 探测里的处置 | 与本条原判断的差异 |
|---|---|---|
| 1 长标签折行 | **三行缝合**：`标签行 → 纯数值行 → 标签行` 合为一行（本次缝合 3 处） | 本条原写「必须基于 x 坐标分列」。缝合是更简单的解法且已跑通；**x 分列仍可能是更稳的解**，两者未做对比，不要把「缝合够用」当成「x 分列不必要」 |
| 2 附注编号列被当数值 | 数值正则要求**两位小数** `^-?[\d,]+\.\d{2}$`，附注号 `5` 天然不匹配 | 本条原写「按列位置剔除，不能按值形状」。**实测表明按值形状在本样本上够用**——但这是**单样本**结论，若有报表列出整数金额就会失效，本条的原判断更稳健，保留 |
| 3 续页 / 母公司混入 | 表标题当作**带 y 坐标的锚点**，区间 = [本标题, 下一标题)，跨页且页内切分 | 一致，且实测 8 张表标题全部正确分离 |
