## 目录为什么不叫 `h2-03`

两个理由，都不是洁癖：

1. `N-71` 已经占了「h2-03」这个号（那是「要不要拿改动后的系统重跑 `h2-02`」）。
2. **「第三轮 H2」这种名字半年后会被读成「第三轮 H2 已完成」。** `h2-02` 就吃过这个亏 ——
   它其实是一次不计分的探针，却顶着一个看起来像正式轮次的名字。
   ⇒ 按**套件**命名，名字自己说清它是什么。

## 你要做什么

1. 打开 [`packets.md`](packets.md)，从 `H2-01` 读到 `H2-21`。
2. **每题限时 5 分钟**，只读那一页。
3. 判 **`对` / `错` / `无法判断`**，填进 [`answer-sheet.yaml`](answer-sheet.yaml) 的 `verdict`。

三条把意思说清楚的（与 `h2-01` 逐字相同，因为口径不能变）：

- **「对」= 你认为系统这次给出的结果是对的。** **拒答也是一种结果** ——
  21 题里有相当一部分是拒答，那时你判的是**「这次拒答对不对」**，不是「这个数对不对」。
- **「无法判断」不是「不确定就选它」。** 它是一个**被单独统计**的读数
  （`EVAL_CASES` §4.3：占比 > 20% ⇒ 即使一致率达标也要补齐证据链重测）。
  选它的意思是：**这一页的信息不足以让我下结论**。
- **留空 ≠ 无法判断。** 没填完的答卷会被拒绝算数（fail-closed）。

## 🔴 这一轮能得出什么、不能得出什么 —— **先读完再动手**

### 一、`W = 0`：`§4.1` 的「≥5 题答错」不满足

冻结后首跑，系统在这 21 题上**没有失败题**（`N-74`）。而 `EVAL_CASES` §4.2 的附注
写明：三档判定的**分辨信号主要来自错答案那一子集**。

| | 这一轮 |
|---|---|
| §4.3 反向检验（「无法判断」占比 ≤ 20%） | 能测。`h2-01` 在这里是 **86.7%**，超限 4 倍，`§4.3` 因此**强制**重测 |
| §4.2 一致率判定门（≥ 80%） | **不作数**。读数全落在正确答案上，测不到「证据页帮不帮得上抓错」 |

⚠️ **`W = 0` 本身有两种解释，我分不开**：可能是系统在语义层上确实稳，
也可能是**这 21 道题不够难**。别把它当成前者的证据。

### 二、🔴 我污染了这一轮，如实记在这里

**我在把题包交给你之前，先跑了评测、读了结果，并在对话里把「21/21 全对」告诉了你。**

后果是直接的：你现在知道答案全对，于是每一个「对」都不含信息 ——
一个知道答案的人判「对」，证明不了页面够用。

- **怎么会这样**：`eval/h2.py` 的 `build_packets` 需要先有跑分结果
  （它只收 `status` 落在 `PASS`/`FAIL` 的题），所以「跑」在工具上**先于**「出包」。
  而 `W` 是否 ≥ 5 又是 §4.1 要你裁的事，不说清就没法请你裁 ——
  两条叠在一起，我没找到不告诉你的路，也**没有在动手前发现这个冲突**。记为 `N-75`。
- **这不是「顺序没安排好」，是工具流程与协议在这里对不上。**
- **已经修了工具，但修不回这一轮**：`eval/h2.py` 现在有 `--blind`
  （盲模式下跑分结果不出 `build_packets`，调用方印不出 `W`）。
  本目录的 [`BUILD.json`](BUILD.json) 如实记着 **`"blind": false`** ——
  这一轮确实不是盲出的，标成盲出就是撒谎。
  算数时 `score()` 会据此把强制标注 `blind_build` 写成「未声明」，
  **那个标注会跟着结论一起印出来**，不会被悄悄省掉。

### 三、那还剩下什么值得做

**一个仍然成立的读法**：不问「答案对不对」（你已经知道了），
只问 **「如果我不知道答案，这一页够不够让我下结论」**。

这正是你在 `h2-01` 自述的判定口径，逐字是：

> 「只根据每一页是否足以『独立判断这次结果对不对』，不把项目中可能泄露的
>   标准答案或历史评测结果拿来反推。『无法判断』代表页面信息不足，而不是犹豫项。」

⇒ 这一轮**能**产出 §4.3 那个读数（「无法判断」占比），而那正是 §4.3 强制重测的那一项。
⇒ 这一轮**不能**产出合格的 `AC-06` / §4.2 一致率。**别把它记成 H2 通过。**

**要不要做，你定。** 21 题 × 5 分钟约 105 分钟。不做也是合法选择。

并且要写明它挡着 Phase 3」——**后半句是错的**。
`PROJECT_SPEC.md:409` 把 `AC-06` 归为**「尽力而为」**类，同节明写
