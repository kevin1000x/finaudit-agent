# H2 复核实验 —— 第二轮（`h2-02`）

> 基点 `22530e2`，种子 `20260909`，15 题普查。
> 本页**不含剧透**，读它是安全的。

## 这一轮和第一轮有什么不同

**第一轮（`h2-01`）的结论是「说不出对错」**，不是「答错了」：15 题里
13 题判 `无法判断`，判「对」0 题、判「错」也 0 题（`A-14`）。
缺的是**页面自足性**——读者知道系统触发了某条规则，但不知道触发得对不对。

`D-038` 因此给证据页补了三节：

| | 补在哪类页面 | 补的是什么 |
|---|---|---|
| `G1` | 作答 | 这个数是拿哪几个数算出来的（字段 + **取值**） |
| `G2` | 触发了口径里某一条的拒答 | 凭什么说满足了这一条（那一条引用的字段 + **取值**） |
| `G3` | 「没有这个指标」 | 当时语义层里有哪些指标（否则这是一句不可证伪的断言） |

`h2-02` 就是拿补完之后的页面重测一次。

## 🔴 复核者是谁：这一轮和第一轮**不是同一种东西**

| | `h2-01` | `h2-02` |
|---|---|---|
| 判卷者 | **操作者本人**（有财务背景，`VERIFICATION.md:1435` 备注「不独立于本项目」） | **三个空白上下文的语言模型**，每个只拿到 5 页正文 |
| 独立性 | 不独立于项目 | 不独立于被测系统（同族模型），但**独立于答案** |
| 专业性 | 有 | **没有** |

**为什么改成这样**：操作者 2026-09-09 取消了「换一位复核者」这道门禁。
理由成立——现有可选项（操作者 / 执行者 / 同族模型）没有一个能提供
当初那个词想要的独立性，而一个永远无法满足的门禁不是门禁，是把项目挂起来的借口。

**但没有改成「执行者自己确认一下」**：H2 测的是「**不知道答案的人**能不能
从这一页判对错」。执行者知道答案，他的判断不含信息。所以拆成两半，
两半都不需要找人：

1. **机械那一半** —— `scripts/check_h2_selfcontained.py`：
   每一页有没有带够「重算一遍所需的东西」。这一半是硬证据，不靠判断。
2. **判断那一半** —— 三个空白上下文子 agent，题包切成三份放在**仓库之外**，
   提示词里明写不许读别的文件、不许搜目录、不许跑命令。

## ⚠️ 这个读数能说明什么、不能说明什么

**能说明**：页面自足性。一个不知道答案的读者，能不能从这一页得出结论。
这正好是 `h2-01` 栽的那一项。

**不能说明**：

- **专业认可**。判卷者是语言模型，它读得懂中文、能核对算术，
  但它**不具备**「这个口径在实务上对不对」的判断力。
- **独立复核**。它与被测系统同族，误差相关。

⇒ `AC-06` 里属于「专业人士会不会认可」的那部分**仍记 `UNVERIFIED`**。
转述这一轮结论时必须连同这两句一起转述，否则就是把「材料齐了」说成「结论成立」。

## 怎么复算

```bash
.venv/Scripts/python scripts/check_h2_selfcontained.py docs/agent/h2-02/packets.md
.venv/Scripts/python -m eval.h2 --suite frozen-01 --sheet docs/agent/h2-02/answer-sheet.yaml
```

```bash
.venv/Scripts/python -m eval.h2 --suite frozen-01 --seed 20260909 --out docs/agent/h2-02
```
