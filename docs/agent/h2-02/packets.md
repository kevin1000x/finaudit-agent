问的是什么
    华鑫科技（900001）2023 年的期间费用率是多少？

答案
    0.12

这个数是拿哪几个数算出来的
    · 管理费用 250000000
    · 财务费用 50000000
    · 营业收入 5000000000
    · 销售费用 300000000

这个数是从哪儿来的
    · 合成夹具（虚构公司与数值），不是任何真实公司的年报
    · 取的是 900001 的 2023 年那一行
    · 口径定义版本 2

用的是哪个口径

期间费用率    period_expense_ratio    版本 2
也叫：三费占比、三费费用率、期间费用占营业收入比
────────────────────────────────────────────────────────────────────

这是什么
    (销售费用 + 管理费用 + 财务费用) / 营业收入

    取数出处（都在年报里，可照着核）
      · 合并利润表 · 销售费用 —— 本期金额
      · 合并利润表 · 管理费用 —— 本期金额（2018 年格式修订后不含研发费
      用）
      · 合并利润表 · 财务费用 —— 本期金额（可为负）
      · 合并利润表 · 营业收入 —— 本期金额
      · 财务报表附注 · 本期是否经追溯重述或会计政策变更调整

    分子就是三个分项加总，这是本指标的定义方式而非缺失时的补救路径。
    允许加总的分项恰为：销售费用、管理费用、财务费用。 不得纳入：研
    发费用（2018 年格式修订后单独列示，纳入会使跨该次修订的年度不可
    比）、 资产减值损失、信用减值损失、税金及附加、其他收益。 任一分
    项缺失时按 「什么时候不给答案」那一节 拒答，不得按 0 补齐—— 缺失
    与「该项为零」是两回事，补 0 会得出一个偏低但看起来正常的费用率
    。

什么时候不给答案（满足任一条即拒答，不猜）
    · 营业收入缺失
    · 营业收入为零或为负，费用率无经济含义
    · 销售费用缺失；不得按 0 处理
    · 管理费用缺失；不得按 0 处理
    · 财务费用缺失；不得按 0 处理

会改变结果的注意事项（6 条）
    · 研发费用不计入本口径。 财会〔2018〕15 号修订报表格式后研发费用
    从管理费用中单独列示， 2018 年前后的「期间费用」不是同一个集合。
    跨该次修订的年度间本指标不可直接比较。
        由哪一条把关： 可比性标记「本期与比较期所依据的准则/公告版本不同
        ，跨版本数值不可直接比较」
    · 分子恰为销售、管理、财务三项费用之和，加总范围由 上面「这是什
    么」里的加总范围说明 限定。 不得纳入减值损失、税金及附加、其他收
    益。
        由哪一条把关： 上面「这是什么」里的加总范围说明
    · 三费中任一项缺失即拒答，不得按 0 补齐。补 0 会得出一个偏低但看
    起来正常的费用率—— 这类静默错误正是本项目要消灭的。
        由哪一条把关： 拒答条件「销售费用缺失；不得按 0 处理」
    · 财务费用可为负（利息收入大于利息支出时），其符号约定为收益记正
    _损失记负， 与销售、管理费用的绝对值列报不同。按绝对值处理会高估
    期间费用率。
        由哪一条把关： 上面「取数出处」里各行的符号约定
    · 分母为零或为负时拒答。
        由哪一条把关： 拒答条件「营业收入为零或为负，费用率无经济含义」
    · 本期经追溯重述时，分子分母均建立在重述后数据上。
        由哪一条把关： 可比性标记「比较期数值经追溯重述或会计政策变更调
        整，与原始披露数不一致」

仅供参考，不影响计算（1 条）
    · 不同商业模式（直销 vs 经销、自建渠道 vs 平台）的期间费用率结构
    差异大， 单一比率不足以判断费用管控能力。

依据
    · 关于修订印发一般企业财务报表格式的通知（财会〔2018〕15 号） 附
    件一 合并利润表格式及编制说明 2018
    · 企业会计准则第 30 号——财务报表列报 第十五条、第十六条 2014

可比性标记（不影响算不算得出，影响能不能跨期比）
    · 比较期数值经追溯重述或会计政策变更调整，与原始披露数不一致

问的是什么
    华鑫科技（900001）2023 年的毛利率是多少？

答案
    0.3

这个数是拿哪几个数算出来的
    · 营业成本 3500000000
    · 营业收入 5000000000

这个数是从哪儿来的
    · 合成夹具（虚构公司与数值），不是任何真实公司的年报
    · 取的是 900001 的 2023 年那一行
    · 口径定义版本 2

用的是哪个口径

毛利率    gross_profit_margin    版本 2
也叫：销售毛利率、综合毛利率、毛利润率
────────────────────────────────────────────────────────────────────

这是什么
    (营业收入 - 营业成本) / 营业收入

    取数出处（都在年报里，可照着核）
      · 合并利润表 · 营业收入 —— 本期金额
      · 合并利润表 · 营业成本 —— 本期金额
      · 财务报表附注 · 本期是否经追溯重述或会计政策变更调整

    禁止由已披露的毛利额倒推本指标的分子。毛利额在不同公司的口径不一
    致 （是否扣除税金及附加、是否含运输费重分类），倒推会引入无法追
    溯的差异。 亦禁止用营业总收入替代分母： 营业总收入含利息收入等不
    与营业成本配比的项目，相除得到的不是毛利率。

什么时候不给答案（满足任一条即拒答，不猜）
    · 营业收入缺失
    · 营业收入为零或为负，毛利率无经济含义
    · 营业成本缺失；不得按 0 处理后得出毛利率 100%

会改变结果的注意事项（6 条）
    · 分母固定取「营业收入」，不取「营业总收入」。后者含利息收入等不
    与营业成本配比的项目。 本定义的取数出处只声明利润表的「营业收入
    」一行，不声明「营业总收入」。
        由哪一条把关： 上面「取数出处」列的那几行（取哪个字段是钉死的）
    · 营业成本缺失时拒答。按 0 处理会得出毛利率 100% —— 一个看起来正
    常的错误数字。
        由哪一条把关： 拒答条件「营业成本缺失；不得按 0 处理后得出毛利率
        100%」
    · 分母为零或为负时拒答。
        由哪一条把关： 拒答条件「营业收入为零或为负，毛利率无经济含义」
    · 营业成本按绝对值列报（正数），公式里作减项。若数据源已按负数提
    供， 符号约定不符会使毛利率翻倍且不触发任何未定义条件 —— 静默错
    误。
        由哪一条把关： 上面「取数出处」里各行的符号约定
    · 财会〔2018〕15 号调整一般企业财务报表格式后，部分公司将运输费
    由销售费用重分类进营业成本， 跨该次变更的年度间毛利率不完全可比
    。本定义不自动识别该重分类。
        由哪一条把关： 可比性标记「本期与比较期所依据的准则/公告版本不同
        ，跨版本数值不可直接比较」
    · 本期经追溯重述时，毛利率建立在重述后数据上，与未重述年度不在同
    一基础。
        由哪一条把关： 可比性标记「比较期数值经追溯重述或会计政策变更调
        整，与原始披露数不一致」

仅供参考，不影响计算（2 条）
    · 分子分母的列报计量单位（元 / 万元 / 千元）若不一致，相除结果会
    差若干数量级。 报表未提供承载计量单位的字段，本定义无法对此设可
    求值规则，故如实标为仅供参考。
    · 不同行业的毛利率水平差异极大，横向比较须限定在同一行业内。
