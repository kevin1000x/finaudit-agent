**当前 §5.1 字段集**（`version: 2` 起，完整示例见 `metrics/net_profit_attributable_excl_nonrecurring.yaml`）：

```yaml
version: 2
grain: {entity: stock_code, period: fiscal_year, period_type: annual}
source_fields:
  - id: is.net_profit_attributable_to_parent
    sign_convention: 收益记正_损失记负     # 参与加减者必填，C4 的落点
    missing_representation: null          # 缺失与零必须可区分，R6 的落点
derivation: {allow_from_components: false, note: 禁止由分项倒推}   # 必填，二选一
standard_basis:
  - {name: ..., issuer: ..., article: ..., version: "2023"}      # 四键缺一即 R5 不合规
flags:
  - {name: restated, trigger: notes.restatement_flag == true}    # 只能引用全局词表
undefined_conditions:
  - {expr: is_missing(notes.x), reason: ...}                     # 必须可求值
common_pitfalls:
  - {text: ..., enforced_by: flags.restated}     # 元规则：二选一
  - {text: ..., advisory_only: true}             # 皆无即不合规
```

**元规则（BREAKING，本次扩展的核心）**：每条 `common_pitfalls` 必须要么有 `enforced_by` 指向可求值规则，要么显式标 `advisory_only: true`。二者皆无 ⇒ 定义不合规。监控：Phase 1 结束时 `advisory_only` 占比 **> 50% 视为元规则失效**，须重新设计。
