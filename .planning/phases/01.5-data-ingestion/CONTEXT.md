## 1. 阶段目标与成功标准

**Goal**：把年报 PDF 变成语义层能消费的结构化字段，并让指标真的算得出数值。

**为什么必须有这一阶段**：Phase 1 结束时 20 份口径定义全部合规，但**没有任何真实数据可喂**，
且 `formula` 只是字符串、受限 DSL 刻意不含算术，**系统算不出任何一个数**。
Phase 2 的 H2 复核实验要求复核者看着**真实数字与证据链**判断——没有真数据，那个实验做不了。

八条成功标准见 `.planning/ROADMAP.md` Phase 1.5 节，此处不复制（避免第二份权威）。
其中 **SC-7（阻断式勾稽校验）与 SC-8（验收看取到的值而非命中数）是 2026-08-16 新增的**，
理由分别在台账 D-13 与 A-4。

## 3. 已实测的事实（不是假设，planner 可直接依赖）

全部于 2026-08-16 在**贵州茅台 2023 年报**（143 页，巨潮下载）上用 **pdfplumber 0.11.5 单库**跑出。
探测代码在 scratchpad，**未进仓库**。

### 3.1 判据已达成（台账 A-4）

| 项 | 结果 |
|---|---|
| 章节定位 | **8 张报表标题全部定位**，合并与母公司**干净分离** |
| 行项目命中 | **15/15**（行在有值 11 ｜ 行在格子空 4 ｜ 整行不存在 0） |
| 勾稽校验 | 资产总计 = 负债合计 + 所有者权益合计，**差额 0.00，通过** |
| y 容差敏感性 | 2.0–5.0 之间结果稳定 |

字段目标集是**用脚本从 `metrics/` 的 20 份定义取出的**，不是凭印象：
全部 30 个 `source_fields` = bs 15 / is 8 / cfs 2 / notes 4 / kpi 1，与 SC-2 的「30 个字段」对得上。

### 3.2 三条必须设计进去的失效模式（台账 A-6）

**都是实测撞出来的，第一版探测因此直接零命中。**

1. **表标题印在上一页的页脚位置**，数据从下一页开始
   ⇒ 任何「标题与锚点必须同页」的规则必然落空。
2. **合并表与母公司表的边界在页内**（p61 上半是合并表尾巴，下半是母公司表标题）
   ⇒ 按「页」定位必然混表。**这正是 D-013 记录的 cninfo
   `extract_financial_statements()`「最后一个匹配的表静默胜出」的成因。**
   **正解**：表标题当作**带 y 坐标的锚点**，区间 = [本标题, 下一标题)，跨页且可页内切分。
3. **行项目标签折行，且数值行夹在两个标签片段之间**：
   ```
   归属于母公司所有者权益
   215,668,571,607.43 | 197,480,041,239.46
   （或股东权益）合计
   ```
   缝合规则：`标签行 → 纯数值行 → 标签行` 三行属同一行项目。

**附注编号列**：数值正则要求两位小数即可排除附注号——但这是**单样本结论**，
遇到列出整数金额的报表会失效，**按列位置剔除更稳妥**。

### 3.3 A-2 的回归数据已就位

茅台 2023 合并资产负债表，六个有息负债分项**全部印在报表上**：

| 字段 | 值 |
|---|---|
| `bs.short_term_borrowings` / `long_term_borrowings` / `bonds_payable` / `trading_financial_liabilities` | **行在，格子空** |
| `bs.non_current_liabilities_due_within_one_year` | 57,054,879.48 |
| `bs.lease_liabilities` | 266,636,234.04 |

**整行不存在的字段：0 个。** 按「格子空 = 0」有息负债率 ≈ **0.00119**，
可算且接近零，而当前定义按 `is_missing` **拒答**。
⇒ SC-3 的回归用例数据齐了。**定义侧不动，修在抽取层。**

## 6. 外部项目的教训（有原文依据，`references/` 可查）

- **cninfo 完全没有勾稽校验**（读完 `pipeline.py`/`metrics.py`/`utils.py`/`downloader.py`/6 个测试）。
  根因是**抽取路径与计算路径不相交**：`pipeline.py:758` 硬编码 `'financial_statements': {}`，
  计算侧从不读它——**它抽了报表，却用 AKShare 的指标算结论**。
  ⇒ 本阶段必须在架构上保证这两条路径是**同一条**。
- **cninfo 的文本路径根本没关联页码**（`pdf_parser.py:94-98` 裸拼接）
  ⇒ **在结构上就不可能产出页级证据链**。页码必须在抽取第一步绑定，事后补不回来。
- **cninfo `pdf_parser.py:302` 无条件把第 0 行当表头**（`pd.DataFrame(table[1:], columns=table[0])`），
  续页表格会**静默吃掉一行真实数据**，而其文档宣称「支持跨页表格识别」。
  ⇒ 表头识别必须是**显式判定 + 留证**。
- **「命中数」这个指标本身能被标签前缀匹配骗过**——我自己中过一次（A-4）。⇒ SC-8。
