## 🔴 覆盖面这件事，得先说实话

产品要「为任意公司现算」，而**我们并没有任意公司的数据**：
财务数值按 `NFR-04` / `D-013` 只能来自巨潮年报 PDF 原文，
而磁盘上真实跑通过的只有三家三年（茅台 2023 / 万华 2019 / 顺丰 2021，
且 `.gitignore` 明令 PDF 不进版本控制）。逐字段人工核对过的是**两家**。

**两条路，本计划选后者**：

| | 做法 | 为什么不 / 为什么是 |
|---|---|---|
| (a) | 请求时现下载并解析年报 PDF | 一次请求要下 + 解一份几百页的 PDF，托管函数的超时扛不住；而且**抽取质量在没核对过的公司上是未知的**，产品会开始输出没人验过的数 |
| (b) | **只对已核验的公司/年份作答，其余诚实拒答** | 覆盖面小，但每一个答案都站得住。**而且拒答本来就是这个系统的正常输出**（`D-003`）——「问了一家我们没数据的公司，它说清为什么没有」正是这个项目想展示的行为 |

**➜ (b) 已落地（`N-61`）。** 覆盖面 = `data/verified/` 里有核对清单的那些，
由 `extractor export` 机械保证：抽到了但没核对过的字段**丢掉并留痕**，
清单里有却没抽到、或值对不上，**整份拒绝导出**。

⇒ **产品的第一版覆盖面 = 我们真的核验过的那些**，页面上写清楚。
把覆盖面装大，一次就把「可审计」这个卖点赔光。

<task id="1" name="把答案路径包成一个无状态端点（与托管商无关，先做）" status="done">

**✅ 2026-09-06 落地。** 实现与计划的一处偏差，记在这里而不是悄悄改：
**没有引入任何 Web 框架。** 对外契约是纯函数 `answer_endpoint(payload) -> (状态码, 响应体)`，
外加一个 stdlib 的本地运行器。两条理由：① 服务端依赖闭包每多一个就多一次
许可证风险（`D-014` 的前提已成真）；② 部署形态是 T4 的决策，
**把 HTTP 框架焊死在这里等于替那个决策先做了选择**。
cninfo 那边是 FastAPI + Pages Function 转发，接上去是十行胶水，写在部署时。


`src/service/api.py`：`POST /answer` 收 `{"question": "..."}`，
返回 `Answer.to_dict()` + `render_answer()` 的正文。**不新增任何业务逻辑** ——
它是 `answer_question` 的一层传输外壳。

- **无状态**：进程内不留任何跨请求的可变状态；`Registry` 与映射表是只读的，启动时加载。
- **没有文件上传**，请求体只有一个字符串（`D-010`）。
- **每一步失败都落成拒答，不抛 500**（`D-022` 的同一条纪律延到 HTTP 边界）。
- 依赖能少则少；新增的每一个都过 `verify_deps.py`。

`tests/test_service.py` 至少守住：
- 端点在**任何**输入下都不返回 5xx（含空串、超长串、非中文、注入形状的串）
- 响应里出现 `render_answer()` 的正文**逐字**（不另写一版渲染）
- **无状态断言**：同一个问题连问两次，两次响应逐字节相同；
  且模块里没有模块级可变容器（语法树查，同 `test_agent_boundary.py` 的做法）

🔴 **做前端的过程中，在浏览器里查出服务端两个缺陷**（都已修 + 加回归）：

1. **证据页把别家公司的年报报成出处。** 问「000651 2023 年的资产负债率」，
   页面答「万华化学 000651 · 2023 年年度报告（年报 PDF SHA-256 87411c60…）」——
   公司名与指纹来自数据源文件，代码与年份来自提问，拼成一条**伪造的出处**。
   根因：`_Sources.at()` 找不到行时退回「第一份」，而第一份现在是一家真实公司。
   ⇒ 改成返回 `_NoRow`（说清「查了哪几份、都没有」），`FixtureSource.batch_id`
   另设第二道防线。**这比答错一个数严重得多** —— 它把「可独立核验的锚点」变成假的。
2. **纯文本证据页里印出 Markdown 星号。** 「只导出了人工逐字段核对过的字段」那句
   带着四个星号出现在用户眼前。源头是写的人默认这段会被 Markdown 渲染 —— 它不会。

**两条都只有真的把页面打开才看得见，跑测试看不见。**
