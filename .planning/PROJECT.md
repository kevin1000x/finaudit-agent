# PROJECT — finaudit-agent

> 建立 2026-08-09。本文件是 GSD 的项目引用，**不是规格**。规格在 `PROJECT_SPEC.md`。

## 核心价值

让 AI 给出的财务分析结论**可以被人独立复核**。

## 一句话定义

给定公开上市公司年报与财务数据，用自然语言提问，Agent 给出答案，并且每个答案都附带完整证据链：用了哪张表、哪个指标口径（含版本）、依据哪条准则、执行了什么、结果哈希是什么。

## 它不是什么

不是通用 Data Agent，不是 ChatBI，不是 NL2SQL 包装，不是企业数据治理平台。

## 差异化

通用 Data Agent 答不出「这个口径对不对」，本项目能答，而且能证明。这一点只有具备财务/审计背景的人做得出来。

## 成功定义

**不是**"做出一个能用的产品"。是：

> 2027 年 3 月前，对 H1（口径可判定性）、H2（证据链可复核性）、H3（图谱必要性）三个假设各得到一个有证据支持的结论。通过或不通过都算成功；只有"做了很多东西但说不清证明了什么"才算失败。

## 相关但独立的项目

`data secret`（POC-0 隐私保护 Agent 基准）验证的是完全不同的假设：同一份程序能否在脱敏视图与隐藏数据间不加修改地转移。本项目验证的是口径可判定性与结论可复核性。**共同点只有方法论，没有实质重叠。**

**本项目不以它的任何进度或结论为前置条件**（D-004 无时序依赖条款）。它当前是 Iteration 1 INCONCLUSIVE、Iteration 2 pre-freeze 阻塞——那是它的状态，不是本项目的约束；它永远停在那里也不影响本项目推进到 Phase 4。反向同样成立。

**两个项目在任何维度上都不互为约束**：不共用语料、不互引结论、不互为前置。原先记的「共用可支配小时数」这一层耦合，也随 2026-08-10 D-008 取消时间预算上限而消失（U-04 因前提不存在而关闭）。仓库、语料、结论完全隔离。
