# 本项目的高代价陷阱

> 这些是**预防性**的告诫。已经真实犯过的错在 `failure-modes.md`。


1. **把非公开数据带进来。** 这是唯一不可挽回的错误（D-010）。任何来自实习、雇主内部系统、客户的字段名、表结构、数值——包括脱敏与聚合后的——都不允许出现。写代码前先问：这个字段名是从哪来的？
2. **从 `data secret` 复制代码或语料。** 机制思想可以借，资产不能搬（D-004）。两个项目的可信度是互相独立的，交叉污染会同时毁掉两边。
3. **先看模型输出再定评测标准。** 评测集一旦冻结就不许为了好看而改（D-012）。发现题目本身错了 → 作废并公开记录，不修改后重用。
4. **为了做图而做图。** 建图前必须先写出 3 个「纯向量 RAG 答不了」的具体问题并证明其答不了（D-007）。
5. **把 TUI 做上瘾。** 它是交付形式不是卖点（D-006），Phase 2 只做到能展示证据链为止。
6. **在语义层没做完时跑去搭 Agent 编排。** 语义层是唯一别人抄不走的一层（D-002）。
7. **流程超过项目。** 三套方法论叠加容易产生 Ceremony Engineering。任一阶段流程开销 > 产出时间的 30% → 删掉贡献最小的那套（D-009）。Harness 要定期做减法。

## 从外部项目源码里实测出来的陷阱（2026-08-22 新增）

**这几条不是告诫，是别人已经踩塌的坑，而且我们的语料形态会精准命中它们。**
出处见 `references/hello-agents-framework-tools.md`。

8. **用 `text.split()` 给中文算相关性——结果恒为 0，且静默。**
   hello-agents 的 `context/builder.py:164-169` 用
   `set(user_query.lower().split()) & set(content.lower().split())` 算重叠度。
   空格分词对中文**不产生任何 token 交集**。
   本会话实测复刻该逻辑：中文 query「贵州茅台2023年的销售毛利率是多少」+ 含答案的中文年报摘录
   → `relevance = 0.0000`；同义英文 → `0.7143`。
   默认 `min_relevance=0.3` 下**每一段中文证据被静默丢弃，不报错不警告**。
   ⇒ **Phase 3 做准则 RAG 时，任何相关性/召回打分必须先在中文样本上验一次「非零」**，
   把「打分恒为 0」做成一条测试，而不是等召回率难看了再回头查。

9. **判据看一个量、执行看另一个量。**
   `truncator.py:97` 用**字节数**判断要不要截断，`:141-150` 的执行只按**行数**切
   ⇒ 实测 60000 字节的**单行**文本返回 `truncated: True` 而 `preview` 一字未减，
   `kept_bytes == original_bytes`。`max_bytes` 形同虚设。
   ⇒ **年报 PDF 抽出的表格文本正是「超长、少换行」**，这条会直接命中。
   凡是「阈值」与「执行」用了不同的量纲，必须有一条测试同时断言两者。

10. **截断算法缺前置检查，把短输入放大。**
    `truncator.py:145-147` 的 `head_tail` 策略不检查「输入是否已经短于目标」，
    实测 10 行输入 → 输出 21 行，**放大 2.1x**。

11. **不可逆压缩 + 一份给它发合格证的测试。**
    `context/history.py:144` 一次整体重新赋值，被压缩的原文**不写任何地方**
    （`grep -cE 'path|save|dump|archive|open\('` 在 `history.py` 为 **0**，
    在同包 `truncator.py` 为 **11**）。
    默认摘要（`core/agent.py:365-383`）返回的是「此会话包含 N 轮对话 / 用户消息 X 条」
    ——**一个字内容都没有，全是计数**。净效果是把 N 条真实对话换成一句
    「这里曾经有 N 条对话」：**这不是有损压缩，是带回执的删除**。
    而 `test_context_engineering.py:117-138` 逐条断言「前 3 轮已消失、只剩一条摘要」并判定通过
    ——**这不是漏测，是被测试确认过的规格**。
    ⇒ 本项目任何「压缩上下文」的动作，**原文落盘位置必须是返回值的一部分**（见 `ARCHITECTURE.md` §8.5），
    且必须有一条测试断言**原文能被找回**，而不是断言「摘要生成了」。
